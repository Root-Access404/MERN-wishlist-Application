# Wishlist App

Simple wishlist application with separate `backend` and `frontend` folders.

## Structure

- `backend/` - Express + MongoDB API
- `frontend/` - React app (Create React App)

## Run locally

Backend:

```bash
cd backend
npm install
npm run dev
```

Frontend:

```bash
cd frontend
npm install
npm start
```

## Notes

- Ensure MongoDB is running and environment variables (if any) are configured.
- This repo will be pushed to your GitHub account; ensure the remote exists or create it before pushing.
